# Build an fdata object from AEMET daily data

Builds an `fdata` object (package fda.usc) with one curve per
station-year and 365 points per curve.

Data can be provided in three ways:

- from an existing data.frame using `df`

- from a file using `file` (`.csv`, `.RData`, `.rds`)

- by downloading data from AEMET through
  [`aemet2df`](https://moviedo5.github.io/aemet2fdata/reference/aemet2df.md)

## Usage

``` r
aemet2fdata(
  station_id = NULL,
  var,
  start_date = NULL,
  end_date = NULL,
  last_n_days = 30,
  api_key = NULL,
  df = NULL,
  file = NULL,
  output_file = NULL,
  verbose = FALSE,
  control = list()
)
```

## Arguments

- station_id:

  Character. AEMET station identifier(s). Required when downloading from
  the API; with `df` or `file` it filters stations.

- var:

  Character. A single variable name, for example `"tmed"`, `"prec"`,
  `"tmin"` or `"tmax"`.

- start_date:

  Character or Date. Initial date in `"YYYY-MM-DD"` format.

- end_date:

  Character or Date. Final date in `"YYYY-MM-DD"` format.

- last_n_days:

  Integer. Number of last days to download if no dates are provided.
  Default: 30.

- api_key:

  Character. AEMET OpenData API key. Used only if data are downloaded
  from the API.

- df:

  Optional data.frame with columns `fecha` (or `date`), `station_id` and
  `var`, as returned by
  [`aemet2df`](https://moviedo5.github.io/aemet2fdata/reference/aemet2df.md).

- file:

  NULL, a file (`.csv`, `.RData`, `.rds`), a vector of files or a
  directory (e.g. the `out_dir` of
  [`aemet2download`](https://moviedo5.github.io/aemet2fdata/reference/aemet2download.md)).

- output_file:

  NULL or character path to save the resulting `fdata` object. Supported
  extensions are `.RData` and `.rds`.

- verbose:

  Logical. If TRUE, prints progress messages.

- control:

  List of advanced parameters passed to
  [`aemet2df`](https://moviedo5.github.io/aemet2fdata/reference/aemet2df.md)
  when downloading from the API.

## Value

An object of class
[`fdata`](https://moviedo5.github.io/fda.usc/reference/fdata.html) with
one row per station-year and 365 columns.

## Details

Only numeric meteorological variables are converted into functional
data. The output has one row per station-year (row names
`"station_year"`, e.g. `"1387_2023"`) and 365 columns, the days of the
year (`argvals = 1:365`).

Leap years: February 29 is removed and the following days are shifted
back one position, so column 60 is always March 1. Missing daily values
are kept as `NA`.

Variable labels and units are assigned from internal AEMET metadata,
e.g.

- `tmed`: main = `"temperature_mean"`, ylab =
  `"Mean daily temperature (°C)"`

- `prec`: main = `"precipitation"`, ylab = `"Daily precipitation (mm)"`

## See also

[`aemet2lfdata`](https://moviedo5.github.io/aemet2fdata/reference/aemet2lfdata.md),
[`fdata`](https://moviedo5.github.io/fda.usc/reference/fdata.html)
